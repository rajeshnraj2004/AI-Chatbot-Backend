# AI Chatbot Backend

Backend server for the AI Chatbot application built using Node.js, Express.js, and MongoDB. This backend handles AI response generation, API routing, database management, and chatbot services for the React Native frontend application.

## ✨ Features

- 🤖 AI response generation API
- 🔐 Secure backend architecture
- 📦 REST API support
- 🗂️ MongoDB database integration
- ⚡ Fast Express.js server
- 🌐 JSON-based communication
- 🧠 Chat history management
- 🔄 API integration support
- 📱 React Native frontend connectivity

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- REST API
